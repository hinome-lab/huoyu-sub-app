# 火羽实时字幕 · Android 客户端

把 `http://123.60.104.22:6006/?k=hy` 这个直播实时字幕页做成了安卓 App，并额外实现**悬浮字幕**：
字幕不再是「只能在网页里看」，而是直接浮在手机任何应用之上——你可以全屏看直播、刷别的 App，翻译字幕始终贴在屏幕上。

## 功能

| 功能 | 说明 |
|---|---|
| 网页壳 | 全屏 WebView 加载原字幕页，视频小窗、翻译、TTS、发弹幕等原有功能全部保留 |
| 悬浮字幕 | 前台服务 + 系统悬浮窗，订阅字幕推送流，**浮在其它应用上层** |
| 中日对照 | 中文翻译大字 + 日文原文小字，可一键切换「仅中文」 |
| 可拖动 | 按住字幕任意位置拖动到屏幕任意角落，位置自动记忆 |
| 可调样式 | 字号 11–40、显示 1–4 行、背景不透明度 0–255 实时生效 |
| 锁定穿透 | 锁定后字幕区域不拦截触摸，边看视频边操作不会误碰 |
| 通知栏控制 | 常驻通知内直接「锁定 / 仅中文 / 停止」，并实时显示最新一句字幕 |
| 断线自愈 | 推送流断开自动重连（指数退避），直播恢复后字幕自动接续 |
| 服务器自动切换 | 网页地址跳到白名单服务器时，字幕服务器地址自动跟着切过去并立即重连 |

## 安装

1. 把 `火羽实时字幕.apk` 传到手机（微信/QQ/数据线均可），点击安装。
2. 首次安装需允许「安装未知来源应用」。
3. 打开 App → 点顶部 **开启悬浮字幕** → 系统会跳到权限页 → 允许 **显示在其他应用上层**。
4. 回到 App，悬浮字幕立刻出现。切到任何应用（含全屏播放器）都能看到。

## 使用技巧

- **拖动**：直接按住字幕拖。
- **控制条**：轻点字幕一下 → 出现 `A−` `A+` `中日` `2行` `锁定` `✕`，6 秒后自动收起。
- **锁定**：点控制条「锁定」后字幕不再吃触摸，可放心操作下面的界面；需要解锁时拉下通知栏点「解锁」。
- **收不到字幕？** 拉下通知栏看状态文字：`连接中…` / `已连接 · N 人在看` / `重连中…`。
- **换直播间**：设置里改「字幕服务器地址」和「密钥 k」即可复用。

## 服务器自动切换

App 内置一份字幕服务器白名单：

```
http://106.15.35.175:6006/
http://123.60.104.22:6006/
http://123.60.104.22:6007/
http://8.133.231.186:6006/
```

当 WebView 的网页地址发生变化（页面跳转、被重定向、单页应用 `pushState` 换地址，或用户手动跳转）时，App 会取出新地址的 `协议://主机:端口` 与白名单比对：

- **命中白名单且与当前服务器不同** → 自动把字幕服务器地址切换成新的这一个，同时更新 `k` 值，并让正在运行的悬浮字幕服务清空旧字幕、立刻重连新服务器。切换时屏幕会弹提示，通知栏状态显示 `已切换服务器 · host:port`。
- **命中但与当前相同 / 不在白名单内** → 不做任何改动。

只看 `协议://主机:端口`，路径与 `?k=` 参数不参与比较；`http` 与 `https`、大小写差异不会造成误判。

开关：**设置 → 「网址变化时自动切换字幕服务器」**（默认开启，取消勾选即关闭该行为）。

## 技术实现

```
字幕服务器 ──SSE(/events?k=hy)──┬──> WebView 网页（原有渲染）
                                └──> OverlayService（前台服务）
                                       ├─ SseClient      解析 line / line_upd / snapshot
                                       ├─ 悬浮窗 WindowManager.TYPE_APPLICATION_OVERLAY
                                       └─ 通知栏快捷控制
```

- 字幕推送协议：SSE，事件 `line`（新句，`ja` 先到、`zh` 译文稍后到）、`line_upd`（补译文）、`snapshot`（历史）、`status`（连接/在线人数）。
- 悬浮窗渲染：`layout` 里中文行 + 日文行，最新一句高亮，历史句降透明度，文字带描边阴影保证压在视频上也能看清。
- 零第三方依赖：只用系统内置 WebView / WindowManager / org.json，APK 体积小、无供应链风险。

## 自己编译

```bash
# 需要 JDK 17 + Android SDK (platform 34 / build-tools 34.0.0)
cd huoyu-sub-app
./build_debug.bat assembleDebug      # Windows
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

> `local.properties` 记录本机 SDK 路径，属于机器相关配置，已被 `.gitignore` 排除。
> 换机器后需先创建该文件（`sdk.dir=E\:\\path\\to\\android-sdk`），或直接设置环境变量 `ANDROID_HOME`。
> `build_debug.bat` 里写的是当前这台机器的 JDK / Gradle / SDK 路径，换环境时按需修改。

## 权限清单

| 权限 | 用途 |
|---|---|
| INTERNET | 访问字幕服务器 |
| SYSTEM_ALERT_WINDOW | 悬浮窗（核心） |
| FOREGROUND_SERVICE / _SPECIAL_USE | 熄屏、切后台后字幕继续接收 |
| POST_NOTIFICATIONS | 通知栏开关与状态 |
