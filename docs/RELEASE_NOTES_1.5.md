## 火羽实时字幕 v1.5

把直播实时翻译字幕从「只能在网页里看」变成「浮在手机任何应用之上」——全屏看直播、刷别的 App、甚至熄屏，中文字幕都贴在屏幕上。

### 本版更新

- 🎨 **悬浮字幕可改颜色**：中文（翻译）与日文（原文）各一套颜色，12 色预设 + RGB 滑杆自由调色，改动立即生效
- 🔤 **字体可换**：7 种系统字体（默认 / 细体 / 中黑 / 特黑 / 宋体 / 等宽 / 窄体），也可从手机导入 `.ttf` / `.otf` 自定义字体
- 🅱 **中文加粗**开关：压在视频画面上更清楚，选「细体」时可关掉
- 💾 **保存本场字幕**（v1.4 起）：一键导出本场**全部**「中文翻译 + 日文原文」到 `下载/火羽字幕`，支持
  TXT 中日对照 / 纯中文 / 中文+时间 / SRT 双语 / CSV / Markdown / JSON 共 7 种格式，数据取服务端留底，不受打开 App 时间影响
- 🔀 **多服务器自动切换**（v1.1 起）：网页地址跳到白名单服务器时，字幕服务器自动跟着切并重连
- ⬆️ **版本检测升级**（v1.2 起）：打开 App 自动查询新版本，有新版弹窗提醒

### 安装

1. 下载下方 `火羽实时字幕-v1.5.apk`
2. 手机上允许「安装未知来源应用」
3. 打开 App → 点顶部「开启悬浮字幕」→ 允许「显示在其他应用上层」

> Android 13+ 会请求通知权限，用于展示字幕状态与通知栏快捷开关（锁定 / 仅中文 / 停止）。
